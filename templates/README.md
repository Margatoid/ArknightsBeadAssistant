# 模板说明

本目录用于存放可选的界面识别模板图片(模板匹配方式)。

## 使用方式

在游戏拼豆活动界面截图后, 用截图工具裁剪出以下区域并保存到本目录:

| 文件名 | 内容 | 作用 |
| --- | --- | --- |
| grid_template.png | 拼豆 24x24 网格区域(尽量包含边框) | 用于自动定位拼豆网格 |
| palette_template.png | 调色板区域(颜色按钮) | 用于自动定位调色板 |

> 说明:
> 1. 模板为可选功能。若没有模板, 程序会尝试网格线检测与颜色区域检测;
>    仍失败时请使用 GUI 中的「界面校准」手动标注区域(推荐, 一次校准永久生效)。
> 2. 模板匹配支持多尺度搜索, 不同分辨率下也可使用, 但建议在常用分辨率下截图。
> 3. 如果游戏界面更新导致自动识别失败, 请重新截图并替换模板。

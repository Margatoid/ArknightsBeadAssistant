# 明日方舟拼豆画像自动拼豆助手

上传任意图片，自动转换为明日方舟拼豆画像活动的 **24x24 拼豆方案**，
并通过 ADB 连接 Android 模拟器，自动识别游戏界面、自动滑动调色板寻找目标颜色、
自动批量点击格子完成拼豆。

> 支持 Windows 10/11，适配 MuMu / 雷电 / 夜神 / 蓝叠 / 逍遥等主流模拟器。

---

## 功能特性

- **图片处理**：支持 PNG / JPG / JPEG / WEBP / BMP；自动居中裁剪为正方形、
  缩放到 24x24、像素化处理、透明背景填充、亮度/对比度调节、孤立色块合并
- **颜色匹配**：内置活动实测 40 色调色板数据库（编号/名称/RGB/页码行列），
  使用 **LAB 颜色空间 + Delta E 2000** 算法精确匹配最接近颜色
- **方案生成**：24x24 预览图 + 施工列表（每种颜色对应的格子坐标）；
  按颜色数量降序自动优化施工顺序（减少调色与切换次数）；
  白色画布底色自动跳过
- **设备控制**：自动查找各模拟器 adb 程序（MuMu `adb.exe`、夜神 `nox_adb.exe`、
  蓝叠 `HD-Adb.exe` 等），自动尝试各模拟器默认端口，支持多开/多设备环境；
  自动获取分辨率、截图、点击、滑动
- **界面识别**：OpenCV 自动识别 —— 白色画布检测 / 网格线检测 / 调色板按钮网格聚类 /
  模板匹配（可选）；识别失败的项自动回退使用校准数据，也可手动校准
- **自动选色**：投影法动态定位颜色按钮（对滚动偏移鲁棒）；目标颜色不在当前屏时
  自动上下滑动调色板，慢速滑动避免惯性过滚，带位置记忆与防滑过头微调
- **自动拼豆**：批量点击（一次 adb 调用连续点 20 格，约 **0.08s/格**，全画布
  576 格约 50 秒）；支持点击间隔与随机延迟、失败自动重试、暂停/继续/停止、实时进度
- **防错误机制**：可配置验证策略（关闭 / 每色首个格子 / 整批截图验证），
  验证失败自动补点重试，避免选错颜色、点错位置

## 模拟器适配

程序自动适配以下主流模拟器（自动查找其 adb 程序 + 自动尝试默认端口）：

| 模拟器 | 默认 adb 端口 | 开启 adb 调试 |
| --- | --- | --- |
| 网易 MuMu 12 | 16384 / 16416 / 16420 | 设置 → 其他 → ADB 调试 |
| 网易 MuMu 6 | 7555 | 设置 → 其他 → 开启 root/adb |
| 雷电 LDPlayer 9/4 | 5555（多开 5556、5557…） | 设置 → 其他设置 → ADB 调试 |
| 夜神 NoxPlayer | 62001（多开 62025…） | 设置 → 其他 → 开启 adb |
| 蓝叠 BlueStacks 5/4 | 5555（多开 5565、5575…） | 设置 → 高级 → ADB 调试 |
| 逍遥 MEmu | 21503（多开 21513…） | 设置 → 其他 → 开启 adb |
| 腾讯手游助手 | 7555 | 默认开启 |

说明：

- 程序依次尝试各端口，任一连上即成功；多开/多台模拟器同时在线时，
  自动绑定当前设备执行命令，互不干扰（连接状态栏显示所用设备）。
- 各模拟器的 adb 程序均与标准 adb 命令兼容，程序自动从常见安装路径查找；
  安装在非常规盘符时，在 `adb_control/adb_connector.py` 的
  `EMULATOR_ADB_PATHS` 中添加路径即可。
- 连接后自动读取设备型号与分辨率，适配任意窗口大小与缩放。

## 安装与使用

```bash
cd ArknightsBeadAssistant
pip install -r requirements.txt
python main.py
```

或双击根目录的 `启动拼豆助手.bat`（自动检查 Python 与依赖，首次运行自动安装）。

使用步骤：

1. **启动模拟器**：打开模拟器，运行明日方舟，进入拼豆画像活动界面
   （建议横屏，任意分辨率）。
2. **启动程序**：`python main.py`（或双击 `启动拼豆助手.bat`）。
3. **连接设备**：点击主窗口「连接设备」，状态变绿并显示所用设备与分辨率。
4. **识别界面**：点击「自动检测界面」；若个别区域识别失败，用「界面校准」
   在截图上点击 4 个点（网格外框四角 / 调色板区域两角）手动标注，一次校准永久生效。
5. **上传图片**：点击「上传图片」，左侧显示 24x24 拼豆方案预览与颜色统计。
6. **调整参数**：点击间隔、批量间隔、验证模式、网格底修等（见参数说明）。
7. **开始拼豆**：点击「开始拼豆」，程序自动执行；可随时暂停/继续/停止，
   进度与日志实时显示。
8. **可选**：点击「导出方案」保存施工列表文本。

## 参数说明

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| 点击间隔 | 单选/重试等单次点击的随机延迟范围（秒） | 0.15~0.30s |
| 批量间隔 | 批量点击中每格的间隔（ms），越小越快；过快游戏可能丢点击，可适当调大 | 60ms |
| 验证模式 | 填充验证策略：关闭(最快) / 首个格子(推荐) / 全部格子(最稳) | 首个格子 |
| 重试次数 | 点击 / 选色失败的最大重试次数 | 3 |
| 网格底修 | 网格区域向下扩展的像素数；若最后一行总点不到，调到 10~20px | 0 |
| 像素风 | 缩放 24x24 时使用最近邻（保留硬边缘，减少边界混色） | 关 |
| 合并孤立色块 | 合并数量很少的孤立颜色，减少调色次数 | 关 |
| 亮度 / 对比度 | 图片预处理调整 | 1.0 |

高级参数见 `config.json`（运行后自动生成）：

| 配置项 | 说明 |
| --- | --- |
| adb_path | adb 可执行文件路径（留空自动查找） |
| connect_ports | 尝试连接的模拟器 adb 端口列表 |
| palette_rows / palette_cols | 调色板每屏可见行数 / 列数 |
| palette_total_rows | 调色板总行数（40 色 / 4 列 = 10 行） |
| skip_canvas_color / canvas_color_id | 是否跳过画布底色（白色）及其颜色编号 |
| color_match_threshold | 调色板颜色识别色差阈值 |
| swipe_settle_ms | 滑动后等待画面稳定时间 |

## 颜色数据库说明

活动 40 种拼豆颜色定义在 `color_match/color_db.py` 中，
每个颜色包含编号、名称、RGB、页码、行、列，LAB 值自动计算。

> 若游戏实际配色或排列不同，直接修改该文件即可，无需改动其他代码。

## 打包 exe

```bash
# 方式一：双击 scripts\build.bat
# 方式二：命令行
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed \
    --name ArknightsBeadAssistant \
    --add-data "templates;templates" \
    main.py
```

输出位于 `dist\ArknightsBeadAssistant.exe`，将 `templates` 目录与 exe 放同一目录
（模板为可选功能）。

## 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 连接失败 | 确认模拟器已启动并开启 adb 调试（见模拟器适配表）；多开时状态栏会显示实际使用的设备 |
| 未找到 adb | 手动在 config.json 中填写 adb_path（模拟器安装目录下的 adb.exe / nox_adb.exe / HD-Adb.exe） |
| 自动识别失败 | 确认正处于拼豆界面（白板+右侧调色板）；网格和调色板可独立识别，失败项沿用校准数据；仍失败请手动校准 |
| 调色板找色不准 | 调低 color_match_threshold；确认校准的调色板区域完整 |
| 验证一直失败 | 关闭「填充验证」；检查校准精度；增大点击间隔 |
| 最后一行总空出 | 图片底行若为白色则自动跳过（画布底色）；若是几何偏移，调大「网格底修」10~20px 或重新校准（点击网格最外侧四角） |
| 分辨率不适配 | 程序按截图像素坐标操作，自动适配不同窗口大小 |
